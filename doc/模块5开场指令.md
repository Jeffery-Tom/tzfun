## 必须做到
1. **建表（项目不自动建表，必须给出 CREATE TABLE SQL 让用户执行）**：
   - `coupon_template(...)` 按子卡字段（type/value/min_spend/max_discount/scope_*/total_count/claimed_count/per_user_limit/各类起止时间/status）。
   - `user_coupon(...)` + **`UNIQUE(user_id, template_id)`**（per_user_limit=1 时天然限领）。

2. **领券 `CouponService.claim(templateId, userId)`**：**推荐顺序（比子卡更稳，绕开 Spring 事务回退坑）**：
   - ① 先 `INSERT user_coupon`（唯一索引拦重复领 → 捕获 `DuplicateKeyException` 直接抛"已领取"，此时还没动 `claimed_count`，无需回退）；
   - ② INSERT 成功后再 `UPDATE coupon_template SET claimed_count=claimed_count+1 WHERE id=#{id} AND claimed_count < total_count`，**行数=0 说明已被领完 → 删除刚插的 user_coupon 行 + 抛"已领完"**。
   - 必须 `@Transactional`，保证①②原子；并发下"唯一索引 + 条件更新"双重防超发。
   - 若 `per_user_limit>1`，唯一索引不够，需额外 `COUNT` 校验（MVP 默认按 1 处理，并在代码注释标明局限）。

3. **抵扣计算 `calcDiscount(template, orderAmount) → BigDecimal`**：满减=value；折扣=orderAmount×(1−rate) 封顶 max_discount；立减=value；结果不超过 orderAmount。

4. **用券/退券（供模块6 调用，本次实现）**：`useCoupon(userCouponId, orderId)`：`UPDATE user_coupon SET status=1, use_order_id=? WHERE id=? AND status=0`，**行数=0 抛"券不可用"**（防复用）；`returnCoupon(userCouponId)`：`UPDATE ... SET status=0, use_order_id=NULL WHERE id=? AND status=1`（取消/超时退券）。

5. **过期任务 `CouponExpireJob`**：`@Scheduled` 扫 `expire_time < now AND status=0` → status=2；**需在配置类或启动类加 `@EnableScheduling`**。

- 复用模块1/2/3/4 资产：`Result`/`CustomException`/`GlobalExceptionHandler`/`UserContext`(领券取 userId)。**禁止重写。**

## 自测（必须做，逐条回报证据）
- 防超发：把某模板 total_count 设小（如 2），连续/并发领第 3 张 → 失败且 `claimed_count` 不超 2。
- 防重复领：同一用户领同一模板两次 → 第二次"已领取"，`user_coupon` 不产生重复行。
- calcDiscount：满减/折扣/立减各测一个值，核对 BigDecimal 结果（注意封顶、不超过订单额）。
- 防复用：对一张券调两次 `useCoupon` → 第二次"券不可用"。
