## 必须做到
1. **接管并扩展模块3 的占位 `Order`**：模块3 建的 `orders` 表/`Order` 实体/`OrderMapper` 是临时占位（字段少），本模块按子卡「表 order」**扩展为完整 schema**（order_no UNIQUE、user_id、store_id、car_type_id、start_time、end_time、status、total_amount/discount_amount/pay_amount DECIMAL(10,2)、coupon_id、create_time、update_time、pickup_info、return_info）。`rebuildFromDb`（模块3）继续可用。
2. **订单状态机 `OrderStatus` 枚举**：PENDING/CONFIRMED/IN_USE/RETURNED/SETTLED/CANCELLED + 合法流转表（ALLOWED）。`changeStatus(orderId, old, new)`：**先查 ALLOWED 合法性 → `UPDATE order SET status=#{new} WHERE id=#{id} AND status=#{old}` → 受影响行数=0 抛并发冲突异常**。**禁止直接 `SET status=?` 不带旧值。**
3. **下单 `OrderService.createOrder(dto)`**：校验时间窗/车型 → 调模块3 `RedisInventoryService.occupy()` 占库存（按日期维度，用 start_time/end_time 的日期部分）→ `total_amount = daily_price × 天数` → `INSERT order(status=PENDING)` 并生成 `order_no` → **占库存或落库失败必须 `release()` 补偿**（成对原则）。
4. **取还车（与状态机联动）**：`POST /order/pickup`（分配 store+type 下 status='在库' 的一辆车，填 pickup_info，→IN_USE）、`POST /order/return`（填 return_info，算超里程/车损 mock 费，→RETURNED）、`POST /order/settle`（→SETTLED）、`POST /order/cancel`（PENDING→CANCELLED + `release()`）。续租/提前还车按子卡可简化并标 TODO。
5. **金额全 DECIMAL**，禁 double/float；`pay_amount`/`discount_amount` 模块4 可先置占位值（discount=0、pay=total），优惠券与真实支付留给模块5/6。
